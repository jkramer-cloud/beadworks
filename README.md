# BeadWorks

**Version 1.5** — Make numbers move.

A standalone educational digital abacus for exploring counting, place value, regrouping, addition, and subtraction.

## Features

- Japanese Soroban, Chinese Suanpan, Russian Schoty (whole-number adaptation), and classroom counting frame.
- Free Play, Build a Number, Addition, and Subtraction.
- Live number display, challenge scoring, and animated beads.
- Five color themes, adjustable board size, optional bead numbering, bead values, place labels, and sound.
- Mouse, touch, and keyboard controls.
- No account or server required.

## Run locally

Open `index.html` in a modern browser. All app code is included in that file.

## Publish with GitHub Pages

1. Create a public repository named `beadworks`.
2. Extract this archive and upload `index.html`, `README.md`, and the optional `.nojekyll` file to the repository root.
3. In Settings > Pages, choose Deploy from a branch, select `main` and `/ (root)`, then save.
4. Open the Pages URL shown in GitHub settings.
